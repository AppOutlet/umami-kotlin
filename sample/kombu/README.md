# Kombu

Kombu is a Umami analytics client made using the [umami-kotlin](https://github.com/AppOutlet/umami-kotlin) library.

Kombu is built with Kotlin Multiplatform and Compose Multiplatform, sharing its UI across Android, iOS, JVM/Desktop, and Web targets.
